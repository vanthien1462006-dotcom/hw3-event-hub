  nowMs) trả về { totalMs, days, hours, minutes, seconds } (hàm thuần, không
  âm); export function startCountdown({ targetIso, onTick, onDone }) trả về

  Mỗi tick tính lại từ Date.now() (KHÔNG đếm ngược bằng biến giảm dần) và lên

  setInterval). stop() phải clearTimeout. Đồng bộ lại khi tab hiện lại
  (visibilitychange).
  5. State machine contract: bảng trạng thái và sự kiện: idle --SUBMIT-->
  submitting; submitting --RESOLVE--> success; submitting --REJECT--> error;
  error --RETRY--> idle; success --RESET--> idle. Sự kiện không hợp lệ bị bỏ
  qua và send() trả về false. Trạng thái được phản ánh bằng thuộc tính
  data-state trên form#register-form để CSS style được. js/form-state.js export
  STATES và createFormMachine({ onChange }) với send(event) và getState().
  6. Sanitization contract: js/sanitize.js export sanitizeText(value,
  maxLength) (chuẩn hóa Unicode NFC, bỏ ký tự điều khiển, gộp khoảng trắng,
  trim, cắt theo maxLength) và escapeHtml(value). Mọi nội dung người dùng hiển
  thị ra giao diện CHỈ qua textContent.
  7. Mock API contract: js/mock-api.js export function mockSubmit(payload) trả
  về Promise, mất ~1200ms, reject khi email kết thúc bằng "@fail.test", ngược
  lại resolve({ id }). In đúng một dòng console.info cho mỗi request (để tôi
